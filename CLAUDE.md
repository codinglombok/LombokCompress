# CLAUDE.md

Rules for Claude Code sessions in this repository.

## Privacy

- Never publish private material without the owner's explicit permission: chat content, chat
  summaries, session links (`claude.ai/code/session_...`), files or screenshots shared in chat,
  and private documents.
- `docs/**/*.md` (masterplan, architecture, changelog and similar) is local-only and ignored by
  git. Do not commit it, quote it, or move its content into public files.
- Commit messages, PR titles/descriptions, review replies and release notes describe the code
  change only.
- Do not add attribution lines (`Co-Authored-By`, `Claude-Session`, "Generated with ...") to
  commits or pull requests. `.claude/settings.json` disables them.

## Workflow

- Ask before pushing, opening a pull request, or posting anything on GitHub. Never merge; the
  repository owner decides.
- Never rewrite published history or force-push without the owner's permission.
